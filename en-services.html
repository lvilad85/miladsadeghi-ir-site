Consultation and getting started

Start with a specific task.

You don’t need to know the tool or solution beforehand. Describe a repeated task and we can see which part can be automated.

01

Understand the current task

Show an example of your daily work. We identify inputs, steps and the needed result.

02

Define what to build

Define what the tool does, the information it needs and where your approval is required.

03

Check it with real work and hand it over

Check and refine the solution using examples of your work, then explain how to use it and follow progress.

Before we start

How do we work out the cost and timing?

It depends on what you need done, the information you have and the tools we’ll use. We’ll agree on what to build, the timing and the cost before we start.

Can it connect to my existing tools?

First, we’ll look at the tools and access you already have. Then we’ll work out what we can connect and what we need to build separately.

I’m not sure what I need. Where do I start?

Describe a repeated task: what information you receive, what you do with it and where the result goes. We use that example to define the need and solution.
